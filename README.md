# Anthony Zarczynski — Portfolio

Personal portfolio site showcasing my work across front-end development, visual design, and CAD/3D modeling.

**Live site:** [anthony-portfolio-sage.vercel.app](https://anthony-portfolio-sage.vercel.app)

## About This Project

This repo holds the source for my personal portfolio — a single-page site with an interactive "I'm looking for…" role selector (Graphic Designer / Web Designer / Front-End Developer) that surfaces relevant skills, live project previews, and links to my work.

The site is currently being redesigned and rebuilt from the ground up. This README will be updated as the rebuild progresses.

## Sections

- **Home** — intro, role selector with skill breakdown, featured project preview
- **About** — full background: education, professional experience, technical foundation
- **Projects** — Recipe Jungle, Preserv, and other selected work, with live interactive previews
- **Contact** — email, LinkedIn, GitHub, resume
